# Dark Mode 深色模式
> 深色模式是一种低功耗、低辐射的显示模式，适用于长时间使用设备的场景。

## 概述
深色模式是一种夜间友好的颜色主题，主要侧重于 UI 界面中每个元素可读性所需的最小色彩对比度，以保证出色的阅读体验。

## 原则
此模式下应优先保证内容识别度，需要确保文本内容易于阅读，尽量避免使用高饱和度的颜色，使用低饱和度或稍微柔和的颜色会减少人眼的视觉疲劳，保证阅读舒适性。      
依据 WCAG2.1 设计标准，文本的视觉呈现以及文本图像至少要有 1:4.5 的对比度，以确保所有的文字内容清晰易读。

## 文字
浅色文本出现在深色背景上时，正文文字和背景的对比度至少要有 1:4.5 ，以确保所有的文字内容清晰易读。
